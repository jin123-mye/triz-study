1창의력의 필요성창의성 정의 · 인물 · 4가지 극복요건

창의성이란

  • 새로운 생각·개념을 찾아내거나, 기존 것을 새롭게 조합하는 것. 결과물은 항상 독창성 + 적합성.
  • 인식 변화: 중세 이전 = 신의 영역·선천적 → 현대 = 후천적으로 확보 가능.
  • 오해: 똑똑한 사람의 것, 타고남, 관리 대상 아님, 거창한 아이디어. 진실: 발상의 전환, 지능·지식과 다른 영역, 누구나 배움, 교육·훈련으로 프로세스 학습 가능.

누가 뭐라고 했나

  • 에드워드 보노: 골프·테니스처럼 누구나 배우는 기술 (연습에 따라 수준 차이).
  • 알트슐러: 선천적 능력이 아님, 체계적 접근을 배우면 기를 수 있음.
  • 에디슨: 창조는 고정관념과의 싸움, “나는 창의적이다”라는 자신감.
  • 창의성은 무에서 유가 아님 — 피카소 “훌륭한 예술가는 복사하고 위대한 예술가는 훔친다”, 아인슈타인 “출처를 숨기는 법을 아는 것”, 잡스 “참조했을 뿐이라 죄책감”.

인물

  • 다빈치: 호기심·수평적 사고·패턴인식. 스티브 잡스: 대담한 상상력. 벅민스터 풀러: 지오데식 돔(30만 개 이상). 로버트 번스타인: 『생각의 탄생』 저자(미시간주립대).

창의성의 의미

  • 상품 관점 = 기발한 아이디어 상품(생활 편리) / 개인 관점 = 문제해결능력(지식의 재조직화) / 기업·사회 관점 = 혁신제품 개발·시장개척(고부가가치).
  • 도요타 자연모사(Biomimetics)도 창의성의 하나.

창의력 향상 4가지 요건 (= 장애요인 극복)

  • ① 심리적 관성 극복 (예: 촛불을 벽에 붙이기, 광고) — 고정관념을 키우는 3요소: 나이·지식의 양·전문성
  • ② 부족한 지식 극복 (개방형 혁신, 기술융합)
  • ③ 올바른 목표 설정 (본질이 왜곡된 목표 → 엉뚱한 문제 해결)
  • ④ 모순 극복 (절충·타협으로 끝내지 않기)
창의성 = 타고나는 것(✗), 학습으로 길러짐(○). 기업 관점은 생산성 향상이 아니라 가치창출·시장개척.
2TRIZ 기본개념(1)사고방법 · TRIZ 탄생 · 문제해결 프로세스

확산적 vs 수렴적 사고

  • 확산적(열린 마음으로 다양한 답): 브레인스토밍, SCAMPER, 마인드맵.
  • 수렴적(한 가지 답을 찾음): 친화도법, 매트릭스도.
  • TRIZ = 수렴적으로 분석해 핵심원인을 찾고, 발산적으로 해결안을 도출. IFR(이상적 최종해)을 향함.

기법 정리

  • 브레인스토밍: 1941년 Osborn(BBDO 광고대리점), 자유발언으로 아이디어 최대한 산출.
  • SCAMPER(Osborn 체크리스트를 Eberle이 보완): S 대체 · C 결합 · M 수정/확대/축소 · P 다른 용도 · E 제거 · R 거꾸로/재배열 · A 다른 영역에 적용.
  • 마인드맵: Tony Buzan, 1970년대 초. 주제 선정 → 중심 이미지 → 가지 그리기 → 수정·보완.
  • 친화도법: 유사성·연관성으로 그룹핑. 매트릭스도: 관련 정도를 1·3·5점으로 평가해 개선안 선정.

분석적 vs 창의적 / 수직적 vs 수평적

  • 분석적: 원인 추구(“범인 찾기”), 연역적, 통계기법(6시그마). 창의적: 바람직한 결과 추구(“연인 찾기”), 귀납적, 주요기법 TRIZ.
  • 수직적: 한 방향으로 깊이 파고듦(탑 쌓기, 구덩이 파기). 수평적: 넓게, 다른 측면에서. 연상에는 둘 다 필요.

TRIZ란

  • 모순의 관점에서 문제를 정의하고, 자원을 활용해 IFR을 도출하게 돕는 문제해결 방법론.
  • 모순이 없는 문제 → 일반 사고방법 / 모순이 있는 창의적 문제 → TRIZ.
  • 알트슐러: 1926 타쉬켄트 출생 → 1946 소련 해군 특허국 특허조사관(이론 토대) → 1950 스탈린 정책 비판으로 25년형 → 1954 석방·이론 정립 → 1961 첫 책 → 1989 러시아 TRIZ 협회. 국내 삼성(1998)·포스코(2010).
  • 20만 건 특허 분석: 어려운 문제엔 모순이 있고, 모순 해결이 진짜 혁신이며, 문제해결엔 일정한 패턴이 있다. (완전히 새로운 문제는 거의 없고 유사한 문제가 존재)

문제해결 프로세스

  • 원리 3가지: 문제 모델링 → 추상화·일반화 → 해결안 응용·유추.
  • 일반화(추상화) 목적: 심리적 관성을 동반하는 용어 대신 기능 서술적 용어로 표현해 사고 범위 확장. 추상 = 불필요한 것은 버리고 본질을 간파(모델링).
  • 유추: 서로 다른 사물의 유사성을 발견해 연결 (예: 민들레 씨앗 → 낙하산).
‘해결안의 발산화’는 TRIZ 원리가 아님. 친화도법은 수렴적, 브레인스토밍·SCAMPER·마인드맵은 확산적.
3TRIZ 기본개념(2)4가지 Key Finding · 4가지 핵심개념

알트슐러의 4가지 Key Finding

  • ① 창의적 문제(Inventive Problem): 하나 이상의 모순이 있고 해결안이 알려져 있지 않은 문제.
  • ② 발명의 수준(Level of Solution): 난이도에 따라 Lv1~5.
  • ③ 시스템 진화의 패턴성: 역동성·유연성·제어성이 커지는(자유도↑) 방향으로 진화.
  • ④ 문제해결의 규칙성: 시대·분야와 무관하게 같은 모순과 같은 해결원리가 반복 (‘다양성’이 아님).

발명의 수준

수준내용비율
Lv5획기적 신개념의 선구자적 발견 (전자레인지)1%
Lv4다른 분야의 과학을 사용한 새로운 발명 (리튬배터리)4%
Lv3공학 분야 지식·기술을 합성 (사이클론 청소기)18%
Lv2산업범위 내 전문지식 활용 개선45%
Lv1동일 분야의 잘 알려진 해결안으로 개선32%

Lv1~2 = 77%(매우 단순한 문제). TRIZ로 얻는 수준은 Lv4~3.

TRIZ 4가지 핵심개념

  • ① 이상성(Ideality) ② 기능(Function) ③ 모순(Contradiction) ④ 자원(Resource) — ‘현실성’은 아님.
  • 이상성 높은 결과(IFR)를 얻으려면 기능이 잘 수행되어야 하고, 방해하는 모순을 주변 자원으로 제거. 지원 도구: 지식, 76가지 표준해, 40가지 발명원리, 분리의 원리, 진화법칙.
  • 이상적 시스템: 기능은 완벽 수행, 자신은 물리적으로 존재하지 않는 시스템. 질량·비용·에너지 소모 → 0, 모순 없음, 유익한 기능만.
  • 기능: 대상(Object)의 속성을 변화시키는 작동 = 대상 + 작용.
  • 모순: 두 사실이 서로 배척해 양립할 수 없는 관계. 기술적 모순(A를 개선하면 B가 악화) / 물리적 모순(한 속성이 +/− 상반 요구). 기존 방법은 회피·타협·최적화, TRIZ는 해결.
  • 자원: 문제 해결에 쓸 수 있는 모든 것. 물질·장(에너지)·시간(변화과정·휴지시기)·공간.
Key Finding 4개에 ‘문제해결의 다양성’은 없음(→ 규칙성). Lv5 = 우연한 큰 발견(초콜릿이 녹은 것을 보고 전자레인지).
4이상적 최종해(IFR)이상성 · 달성 3방법 · 7가지 질문

이상성

  • 이상성 = 유용한 기능의 합 ÷ (해로운 기능의 합 + 비용의 합). 곱하는 게 아님.
  • “더 이상 더할 게 없을 때가 아니라 더 이상 뺄 게 없을 때 완성된다.”
  • TRIZ의 문제해결 = 여러 해결안 중 이상성이 가장 높은(IFR에 가까운) 해를 찾는 것. IFR = 유용한 효과만 있고 해로운 효과는 없는 상태.

IFR의 목적·특징

  • 목적: 문제의 초점을 명확히, 해결 방향 제시, 발산 방지(목표 한 곳으로), 고정관념·심리적 관성 탈피.
  • 특징: 유해한 특성 제거 / 장점 유지·증가 / 복잡하게 만들지 않음 / 무료·가용자원 이용 / 새로운 유해효과 도입 안 함.

IFR 달성 3가지 방법

  • ① 시스템 없이 원하는 결과가 달성되도록 구성
  • ② 대상물 스스로 원하는 결과물이 되도록 구성 (셀프서비스, 자동문, 무인자동차)
  • ③ 시스템 구성을 단순화 (핸드폰·오디오 구성 단순화)

IFR 달성을 위한 7가지 질문

  • ① 시스템의 최종 목표는? ② IFR은? ③ 무엇이 IFR 달성을 방해하나? ④ 왜 방해하나? ⑤ 어떤 조건이면 방해를 없앨 수 있나? ⑥ 이용 가능한 자원은? ⑦ 해결된 유사 사례(타 분야 포함)는?
  • ⑦번은 다양한 문제해결 도구와의 연결고리, 특정 분야에 한정하지 않고 포괄적으로 생각하게 함.

사례

  • 합금시편 부식시험: 고온의 산에 용기가 부식, 유리는 균열, 플래티늄은 예산 없음 → IFR = 주어진 자원으로 누수 없이 시험 → 주변 자원 이용 + 자원(시험재료)이 스스로 수행.
  • 세탁: IFR = 세탁기(세제) 없이 옷을 세탁 → 옷과 때의 결합력을 약화시킬 다른 방법 → 물을 이온화(2001 대우전자), 무세제 세탁기.
“자원을 사용하지 않을 수 있는가?”는 7가지 질문에 없음(⑥은 “어떤 자원이 이용 가능한가?”).
5기능(Function) 이해기능 · 속성 · 기능 분석

기능

  • 대상(Object)의 속성(Feature)을 변화시키는 작용(Action). 기본요소 = 작용 + 대상 (도구는 기본요소 아님).
  • 사물이 존재하는 근본적인 이유로 사고. 표현은 행위가 아니라 사용 의도로, 동사·명사로 간단히.
  • 정의 목적: 관련자와 공통 인식, 문제 있는 기능 파악, 기존 형상·개념에 의한 사고 제한 타파.
  • 순서: 원하는 결과 → 기능 도출 → 그 다음에 도구를 찾음. 같은 도구도 원하는 결과에 따라 기능이 달라짐.

속성 변화의 6가지 표현

  • 유지(Keep) · 변경(Change) · 증가(Increase) · 감소(Decrease) · 이동(Move) · 차단(Cover)

속성과 속성값

  • 대상은 속성으로 설명. 예) 색(속성) — 적·청·백(속성값), 강도(속성) — Kg/mm²(단위), 모양 — 원형·사각형.
  • 속성은 측정 가능하거나 제어 가능한 물질의 특성.
  • 속성 변화 예: 상변화(증기기관), 기화열(젖은 수건+선풍기로 맥주 냉각, 우주선 보호층 증발), 열팽창·수축(바이메탈 온도계, 화재경보), 색·투명도 변화, 유색 첨가제(투명 독극물을 붉게).

기능 분석

  • 목적: 구성요소 간 기능적 관계를 기술, 문제기능 파악·개선, 문제상황 시각화로 객관적 정의·심리적 타성 극복, 자원 파악, 선택과 집중.
  • 순서: ① 구성요소 탐색 → ② 도구·대상·작용 정의(도구·대상은 원하는 결과로 결정) → ③ 결과에 따라 작용 표시.
  • 작용의 상태: 충분 · 불충분 · 과도 · 해로운. 기능의 종류: 유용기능(요구된 기능) / 유해기능(원하지 않는 결과 발생).
  • 기능모델 = 속성을 단순화해 문제를 찾아 풀어나가는 사고변환 공식.
기능 기본요소에 ‘도구’를 넣으면 오답. 속성은 ‘제어는 불가능해도’가 아니라 제어 가능.
6기술시스템구성 · 계층구조 · 9가지 발전 법칙

기술시스템이란

  • 기능 수행을 위해 서로 관련을 맺은 구성요소들의 집합체. 목적은 기능 수행. 느슨한 원시시스템의 요소들이 기능으로 연결될 때 출현(전통 주방 → 스마트 주방).
  • 구성요소: 엔진(에너지 발생) · 전달장치 · 제어장치 · 도구(작동기관). 대상은 구성요소가 아님.
  • 기능 수행 조건 4가지: ① 필수 구성요소가 모두 있어야 ② 최소 하나는 제어되어야 ③ 모든 구성요소 사이에 에너지 전달 ④ 각 요소의 동작이 조화.
  • 문제 = 엔진이 동력을 못 내거나, 전달이 안 되거나, 도구가 제대로 작용 못하거나, 제어가 안 되는 경우.
  • 주사기: 기능=피부 내 주사액 주입, 대상=주사액, 도구=피스톤, 엔진=손, 전달=피스톤 막대, 제어=머리, 에너지원=몸.
  • 예) 자동차=사람 이동, 엔진=동력 발생, 바퀴=땅을 밂, 헤어드라이기=물 증발.

계층구조 · 특징

  • 기술시스템은 상위시스템·하위시스템과 상호작용, 주변에 환경 존재.
  • 가장 간단한 시스템 = 두 개 요소 + 에너지 상호작용(칠판과 분필). 하위시스템의 변화는 상위시스템의 변화를 가져옴 → 체계적 접근 필요.

7자원(Resources) 활용자원 종류 · 분석 · 과학적 효과

자원이란

  • 포스코 “자원은 유한, 창의는 무한” — 하지만 문제해결적 사고에서는 자원도 무한. 창조 = 기존에 존재하던 것을 자원으로 삼아 새것을 만드는 것.
  • 자원을 잘 활용한 인물: 맥가이버, 이순신, 뉴턴.

자원의 종류

  • 형태별: 물질 자원(유형: 구리판·유리·스팀·엘리베이터…) / 장 자원(무형: 전기·자력·유도체의 힘·흐름…) / 공간(영역) / 시간(변화과정·휴지시기) / 기타(사람·정보·환경).
  • 위치별: 환경 자원(주위에서 쉽게 구함) / 상위시스템 자원 / 시스템 자원(도구·대상).
  • 장의 종류: 기계 · 음파 · 열 · 화학 · 전기 · 자기.

자원 분석·활용

  • 목적 3가지: ① 새로운 아이디어 도출 ② 모순의 해결 ③ 시스템 진화 예측.
  • 도출 가이드: 심리적 관성을 버리면 자원이 많이 나옴 / 목적과 범위를 정하기 / 조건에 따라 달라지면 스스로 조건을 만들기 / 실현성에 얽매여 작은 기회를 버리지 않기.
  • 활용 사례: 서산 간척지(1980, H건설), 스히폴 공항, 냉동 해동 지시기, 변압기 이동(알트슐러). 자원의 변화 = 물질 변화 / 장 변화 (청진기·봉화는 장의 변화).
